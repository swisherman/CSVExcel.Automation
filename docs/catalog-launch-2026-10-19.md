## Submitted FAQs

**Do I need Microsoft Excel installed to run the tool?**
No. The delivered Windows tool processes supported CSV and XLSX files without Microsoft Excel installed. You can open the output in Excel or another compatible spreadsheet application.

**What counts as a file layout or processing rule?**
A layout is one distinct set of input column headers mapped to the agreed output columns. A simple rule is one mapping, trim, required-field check, type or range check, or filter. We agree on the layouts and rules before work begins.

**Will the tool change my original files?**
No. Original input files remain unchanged. Each run creates a separate output folder containing clean CSV and XLSX files, an exception report with rejection reasons, and a summary of processed records.

**Can the tool process formulas, macros or protected workbooks?**
This offer covers CSV files and unprotected XLSX worksheets containing values. Formula calculation and macros are excluded. Formula cells are rejected; export or copy their calculated results as values before processing.

**Can you add API connections or scheduled processing?**
Live API connections, scheduled execution and joins between datasets are outside these packages. Contact me before ordering to discuss whether your workflow needs a separately scoped project.
