## Title
I will automate your Excel CSV data processing and reporting

## Buyer-facing description
Do you repeatedly merge spreadsheets, rename columns, remove duplicate records or prepare the same report?

I will build a reusable C# tool for your agreed CSV or Excel workflow. Depending on the package, it can combine files, map columns, validate required fields, identify duplicates and export clean data with a report explaining rejected records.

You receive the agreed executable, C# source, configuration, sample inputs and outputs, and clear run instructions. The tool processes files without requiring you to repeat the cleanup by hand.

Please message me with sanitized sample files, the output you need, your typical file size and your Windows version before ordering. I will confirm the workflow and scope first.

Live API connections, complex reconciliation, macros and two-way synchronization require a separate quote.

Price or delivery changes require a new scope agreement. Hosting, service subscriptions and paid APIs are excluded. Basic and Standard do not include live APIs.
A simple rule is one agreed trim, mapping, required check, type/range check or filter. A revision adjusts behavior within the approved workflow; new integrations/schemas/outputs are new scope. Proposed 14-day defect-fix window after delivery for reproducible errors within agreed scope; no indefinite support.

## Buyer requirements
1. What manual steps do you perform today, and how often?
2. Upload sanitized inputs and an example of the exact desired output.
3. Which columns uniquely identify a record? What should happen to duplicates/conflicts?
4. Which sheets, delimiter, encoding, dates/currency and formulas are involved?
5. Typical/largest files, rows and columns?
6. Windows version and how you want to run the tool?
7. Does it need exports only, or an actual connection to another service?
8. Who will approve the acceptance output? Any data-retention constraints?
Never ask buyers to place passwords or tokens in public files or source code.

## FAQ
Is this just a cleaned spreadsheet? No. The service delivers a repeatable tool for the agreed workflow.
Do I need Excel installed? Not for supported CSV/XLSX file processing; Excel helps review the result.
Can it update my store or accounting app? Potentially, after separate discovery of API access, field mapping and write behavior.
Can it run automatically? Scheduled Windows execution is a separately agreed Premium feature after verification.
Will it handle every workbook? Support is agreed from samples. Legacy XLS, macros, protected files and arbitrary formula calculations are excluded by default.

## Delivery checklist
Approved scope and samples; release built on Windows; acceptance results matched; negative cases checked; third-party notices included; source and executable scanned for credentials; run/recovery instructions; demo data included; limitations and support period recorded.
